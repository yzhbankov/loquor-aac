# Brand assets

The loquor mark: two devices facing each other, a signal between them.

| file | use it for |
|---|---|
| `loquor-logo-horizontal.svg` | headers, READMEs, slides, websites — scales to any size (1600 × 450 viewBox) |
| `loquor-logo-stacked-1024.png` | square placements: social previews, posters, the top of a document |
| `loquor-app-icon-512.png` | app and launcher icons, favicons, avatars (rounded square, dark background) |

Colours: cyan-to-blue gradient on the left device (`#24DDF0` → `#1343F8`),
violet gradient on the right (`#C266FA` → `#4B2DE6`), wordmark in navy
`#0A1E45` on light backgrounds. Keep the mark's proportions; do not recolour or add
effects. Use the icon, not the wordmark, below 32 px.

In Markdown on GitHub:

```html
<p align="center"><img src="assets/loquor-logo-horizontal.svg" width="420" alt="loquor"></p>
```
